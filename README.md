# 带薪养花 · 工位微园艺

> 老板回头的 0.5 秒，我假装在做表。

45 秒、单手可玩的工位微园艺网页小游戏。

## 在线玩

**https://yej1a.github.io/paid-to-bloom/**

iPhone：Safari 打开 → 分享 → 添加到主屏幕。  
Android：直接浏览器打开，也可以下载 [Android APK v1.1](download/paid-to-bloom-v1.1.apk)。

## 玩法

按住屏幕浇水，老板回头前松手切回 Excel；在最后 0.5 秒的红格内松手，会触发「秒切！演技 +180」。45 秒内把花养开，结算生成一张工位战报卡。

## 本地运行

纯静态页面，直接用浏览器打开 `index.html` 即可；或：

```bash
python -m http.server 4173
```

然后访问 <http://127.0.0.1:4173/>。
