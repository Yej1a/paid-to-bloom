# 带薪养花 · 工位微园艺

> 老板回头的 0.5 秒，我假装在做表。

45 秒、单手可玩的工位微园艺网页小游戏。

## 在线玩

**https://yej1a.github.io/paid-to-bloom/**

iPhone：Safari 打开 → 分享 → 添加到主屏幕。  
Android：直接浏览器打开，也可以下载 [Android APK v1.3](download/paid-to-bloom-v1.3.apk)。

## 玩法

开局选一盆花（小雏菊 / 向日葵 / 仙人掌），系统随机抽一个老板（在吗型 / 咖啡型 / 巡查型）。按住屏幕浇水，老板回头前松手切回 Excel；在最后红格内松手，会触发「秒切！演技 +180」。

老板不只回头：会假动作接电话、走开半秒又回马枪、接电话/续杯给安全窗口，也会探过隔板盯着你。一局分三幕，越到后面越刺激。

花谱记录每盆花的「已认识 / 已养开」两枚章，见过就收录，养开才盖章。

## 本地运行

纯静态页面，直接用浏览器打开 `index.html` 即可；或：

```bash
python -m http.server 4173
```

然后访问 <http://127.0.0.1:4173/>。
